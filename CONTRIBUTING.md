# Contributing

Bug reports, documentation fixes, hardware notes, and firmware improvements are welcome.

Before submitting a code change:

1. Keep changes focused and easy to review.
2. Preserve the existing hardware defaults unless there is a clear reason to change them.
3. Explain any wiring or behavioural changes in the pull request.
4. Test on an Arduino Nano ESP32 and original Xbox 360 Chatpad when hardware is available.
5. Update the README or documentation when user-facing behaviour changes.

For substantial changes, opening an issue first is encouraged so the approach can be discussed before a large patch is written.
